# 🌡️ Conversor de Temperaturas

Aplicativo web responsive para convertir temperaturas entre **Celsius (°C), Fahrenheit (°F) y Kelvin (K)**.

## Funcionalidades

- Conversión automática.
- Celsius ↔ Fahrenheit.
- Celsius ↔ Kelvin.
- Fahrenheit ↔ Kelvin.
- Intercambio de unidades.
- Botón para limpiar.
- Validación de valores.
- Validación de Kelvin inferior a 0 K.
- Indicador visual de temperatura fría, templada o caliente.
- Diseño responsive para computador, tablet y celular.
- Sin backend ni base de datos.
- Sin frameworks ni dependencias.

## Tecnologías

- HTML5
- CSS3
- JavaScript Vanilla

## Ejecutar localmente

No necesitas instalar nada.

Simplemente abre `index.html` en cualquier navegador moderno.

## Subir a GitHub

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, la carpeta `css`, la carpeta `js` y `README.md`.
3. Verifica que `index.html` quede en la raíz del repositorio.
4. En GitHub entra a **Settings → Pages**.
5. En **Build and deployment**, selecciona:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
6. Guarda los cambios.
7. GitHub Pages generará la dirección pública del sitio.
